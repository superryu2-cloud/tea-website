# Tea Website（Vite + React + Tailwind）

## 🚀 快速開始（一鍵啟動）

**最簡單的方式：** 雙擊執行 `start_website.bat`

腳本會自動完成：
- ✅ 檢測 Node.js 環境
- ✅ 引導安裝（如需要）
- ✅ 安裝專案依賴
- ✅ 啟動開發伺服器
- ✅ 自動開啟瀏覽器

**詳細說明：** 請查看 [快速啟動指南.md](file:///d:/tea-website/快速啟動指南.md)
