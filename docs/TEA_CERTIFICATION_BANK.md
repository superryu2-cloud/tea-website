# 茶藝師檢定（國考）系列維護

入口：品評考題 → 茶藝師檢定（國考）。現有「茶藝師」題庫保持獨立。

目前 batch-001 收錄使用者提供的 HTML 中全部 158 題、7 個分類。另有約 1,700 多題國考資料整理中，此為待補資料估計數量，不代表已收錄；沒有建立空白題目。繁體欄位 q_tc / opts_tc 對應題幹與選項，保留英文題、原答案和特殊答案備註。

## 新增批次

2026-10-17 更新：batch-002 補入原題號 159–600，共 442 題；目前合計 600 題。前 158 題與新版完全一致，保留原有 ID 與作答紀錄。匯入工具會略過一致的既有題目；若既有題目的內容或答案改變，會停止並要求人工校對。

1. 相同 HTML 格式可執行 `node scripts/import-tea-certification.mjs "來源.html" batch-002`，僅解析 JSON，不執行 HTML。
2. 校對分類、題幹、選項與 note 均為繁體中文；來源只有簡體時，先完成繁體轉換與校對，不直接匯入。
3. 在 `public/data/tea-certification/manifest.json` 的 batches 加入 `batch-002.json`。
4. 每題 ID 使用 `tea-cert-批次-原題號`；同一題修訂時保留 ID，以維持既有作答記錄。新批次若與舊題重複，人工比對後再決定是否加入。
5. 分類以原始分類名稱為穩定 key，新增分類自動出現在選單。各批次使用獨立檔案，不必更動元件。
6. 執行 `node scripts/verify-tea-certification.mjs`、`npm run build` 後部署。

列表每頁 30 題，避免後續數千題同時建立畫面元素。搜尋、翻卡與測驗仍使用完整已收錄題目。

## 國考與省考分開管理

2026-10-17 補充：batch-003 新增 967 題，現有總計 1,567 題。新來源包含 595 題單選、172 題複選及 200 題是非；其中一題標為單選但答案為 ABCD，依多答案處理。新來源對舊題有文字及缺漏差異，前 600 題保留。題號最高 1761，缺號沒有補造。新增的 126 題缺少答案或選項，保留可閱讀內容與缺漏標示，暫不計分。

複選題支援題庫練習多選核對與翻卡。快問快答和自訂測驗僅抽答案與選項完整的單選、是非題。空括號統一顯示（＿），移除填空外層中英文引號。

可執行 `node scripts/verify-tea-certification-supplement.mjs "來源.html"` 核對本批資料；`--new-only` 匯入模式只補未收錄原題號，不覆寫舊題。使用此模式前必須先比對並記錄舊題差異。

現有 tea_certification 為國考系列，保留既有 bank、topic 與題目 ID，避免影響作答紀錄。省考資料尚在整理，預計上千題；收到後另建獨立 bank、批次目錄與題目 ID 前綴，不放入國考 manifest。
