## 1) 這個專案是什麼

- 類型：Vite + React + Tailwind 的靜態教學網站（可部署到 Cloudflare Pages）
- 目標使用者：你自己（備課/整理）＋國外老師（教學素材）＋學生（參考資料）
- 內容策略：以「茶知識資料庫」為核心，逐步發展成可規劃課程與學習旅程的網站（未來可加登入）

## 5) 本機開發方式（Windows）

在專案資料夾內執行：

1. 安裝套件（第一次或套件有變更時）
   - `npm install`

2. 啟動開發伺服器
   - `npm run dev`
   - 看到提示後用瀏覽器開：`http://localhost:5173/`

3. 檢查
   - `npm run lint`
   - `npm run build`

## 6) 上線（Cloudflare Pages）工作方式（建議流程）

你現在的 Pages 網址（你提供）：  
`https://tea-website.pages.dev/`

建議採用「GitHub 連動自動部署」：

1. 本機改完內容
2. `git commit`
3. `git push` 到 GitHub
4. Cloudflare Pages 會自動 build + deploy

### 常見卡關（你之前遇到過）

- 直接點 `upload_to_github.bat` 會「閃退」
  - 多半原因：你不是在「git clone 下來的資料夾」內執行，或不是用 `.\upload_to_github.bat` 方式在 PowerShell 執行

- 出現 `This folder is not a Git repository`
  - 代表資料夾內沒有 `.git/`，不是 git repo

- `git clone ...` 顯示 `destination path ... already exists and is not an empty directory`
  - 代表你要 clone 的目錄名已存在；要換一個資料夾名稱或先移走原資料夾

## 7) 內容與設計方向（目前共識）

你希望的整體感覺（重點）：
- 不要像「純資料庫」或「硬邦邦的學習網站」
- 更像「茶席／茶道」：清爽、留白、有空間，但內容完整
- 架構希望有層次：六大茶類 → 品種 → 茶葉科學（氧化→烘焙→內含物）→ 製程 → 台灣特色茶 → 沖泡 → 茶藝（茶道）

你不想要的 UI：
- 寫給你看的提示/提醒（例如「提示：如果你接下來還會補充…」）
- 過多的浮動視窗遮擋內容（例如右下浮動導覽）
